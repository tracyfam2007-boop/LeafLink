# LeafLink

## Project Overview

LeafLink is an academic web application project developed to provide users with an interactive platform featuring activities, rewards, badges and team challenges.

The system includes an administrative module that allows administrators to manage users and oversee different platform activities.

## Technologies Used

- PHP
- MySQL
- CSS
- HTML
- Java

## Main Features

- User Management
- Activity Management
- Reward Management
- Badge Management
- Team Challenge Management
- Abnormal Report Management
- Admin Dashboard with Charts
